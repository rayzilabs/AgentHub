# taiwan-law 關鍵字找相關條文：調查報告（KAN-20 階段一）

日期：2026-11-23

## 問題

`search_taiwan_laws` 只帶關鍵字、而且關鍵字不是法規名稱時，目前的流程是：

1. 打 `LawSearchResult.aspx?ty=ONEBAR&kw=…` 取得法規清單（預設依「法規名稱少→多」排序）。
2. 取前 `min(limit, 5)` 部，抓整部全文頁（LawAll），用關鍵字字串比對條文；**比對不到就退回前 6 條**。

「競業禁止」的清單第 1～5 名是公司法、民法、金融控股公司投資管理辦法、保險法、勞動事件法（預設 `limit=3` 只取前 3 部），勞基法排第 6、勞基法施行細則排第 7，所以查不到；公司法、民法的相關條文不含「競業禁止」字樣（見下方「相關詞」），字串比對失敗，就退回第 1～6 條。

## 做法一：全國法規資料庫的官方條文檢索

### 端點

| 用途 | 網址 | 說明 |
|---|---|---|
| 哪些法規有條文含關鍵字 | `LawSearchResult.aspx?cur=Ld&ty=ONEBAR&kw=<關鍵字>&set=LPCODE%7CASC&psize=60` | 「法條內容」清單，依位階排序，附 pcode 與修正日期。單次 GET 即可；`psize` 只收 20、40、60，其他值會被導到錯誤頁。多個詞用空白隔開是 AND。**清單混有已廢止的法規**（`<span class="label-fei">廢</span>`），一定要濾掉。 |
| 某部法規裡哪些條文含關鍵字 | `LawClass/LawSearchContent.aspx?pcode=<pcode>&kw=<關鍵字>` | 只回命中的條文，每條有 `LawSingle.aspx` 官方網址。條文有 `law-article` 與 `text-pre` 兩種排版；有附件的條號前面多「本條文有附件」字樣；查不到時顯示「查無資料」。 |

官方檢索有「相關詞」擴充：公司法第 120 條、民法第 562、563 條的條文沒有「競業禁止」四個字，一樣會命中。

## 做法二：本地條文索引

來源是法務部開放 API（資料日期 2026-11-13）。

| 範圍 | JSON | gzip |
|---|---|---|
| 現行法律 1,029 部 | 16.6 MB | 4.3 MB |
| 法律＋勞動部主管命令（258 部） | 19.4 MB | 5.1 MB |
| 法律＋全部命令（7,255 部） | 72.6 MB | 18.9 MB |

50 MB 上限算的是 zip 大小，所以三種都放得下；不收全部命令是因為 MCP 要整份載入記憶體。比對一個關鍵字約 10 毫秒。命令 API 調查時曾連續回 500（連打 4 次沒有間隔），稍後恢復正常。

| 關鍵字 | 只收法律 | 法律＋勞動部命令 | 法律＋全部命令 |
|---|---|---|---|
| 競業禁止 | 勞基法 9-1、勞動事件法 2 | 再加施行細則 7-1～7-3 | 10 條 |
| 試用期 | 6 條 | 6 條 | 24 條 |
| 定型化契約 審閱期 | 消保法 11-1 | 同左 | 同左 |
| 職業安全衛生法 申訴（整串） | 0 | 0 | 0 |

用「提到關鍵字的次數」排序的效果好：資遣費→勞基法、個人資料 蒐集→個資法、股東會 召集→公司法、商標 侵害→商標法。「加班費」不行（勞基法用「延長工作時間之工資」），這是字面比對的限制。

## 比較

| | 官方檢索 | 本地索引 |
|---|---|---|
| 資料 | 即時 | 最多落後一個月，租用者鎖定版本後不會更新 |
| 範圍 | 法律、全部命令、相關詞 | 法律＋勞動部命令，字面比對 |

## 決定與做法

使用者選「官方＋本地索引備援」（2026-11-23）。詢問時的說明有兩點錯誤，後來更正：命令 API 的 500 是暫時的；備援收勞動部命令就找得到施行細則。

1. 查詢裡有獨立的法規名稱又有其他詞（「職業安全衛生法 申訴」）：只查那部法規的 `LawSearchContent`。黏在一起時（「勞基法資遣費」）分不清是不是別的詞（「公司法律責任」），先用完整關鍵字查清單，查不到才拆開查。
2. 沒有法規名稱：官方清單濾掉已廢止的，依本地索引提到關鍵字的次數排序，抓前 `limit` 部的條文頁，每部最多 6 條，其餘列在 `other_laws`。清單超過 60 部時，本地索引命中的法規也列入候選。
3. 清單取不到或看不懂：整個改用本地索引；單部條文頁失敗：只有那部用本地索引，沒有就列在 `unavailable`。本地結果一律標 `data_date`。
4. 官方查無結果：回空結果與說明，不退回第 1～6 條。
5. 附生效註記（例如職安法、個資法有尚未施行的修正條文）與註記的資料日期。
6. 只查法規名稱、或帶條號時維持原本的行為。
