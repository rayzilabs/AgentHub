# 讓顧問用到你需要的 Python 套件

顧問執行 Python 時，平台已經預裝 `numpy` 和 `pandas`。需要其他套件時，在 skill 資料夾放一份 `requirements.txt`，平台會替這位顧問建立自己的環境並安裝。

## 放在哪裡

和 `SKILL.md` 放在同一個資料夾：

```text
skills.zip
└── quant-report/
    ├── SKILL.md
    └── requirements.txt
```

同一個 zip 裡有好幾個 skill 都放了 `requirements.txt` 時，平台會依資料夾名稱排序後合併成一份安裝。

## 可以怎麼寫

一行一個套件，只能寫 PyPI 上的套件名稱與版本：

```text
requests==2.32.3
scipy>=1.11
openpyxl
# 這行是註解
```

- 可以用 `==`、`>=`、`<=`、`~=`、`!=`、`<`、`>`，多個條件用逗號隔開，例如 `scipy>=1.11,<2`。
- 可以寫 extras，例如 `pandas[excel]`。
- 不接受 `-` 開頭的選項（`-r`、`-e`、`--index-url`…）、網址、`@`、本機路徑和環境標記（`;`）。
- 一份最多 50 個套件、4096 bytes。

上架（上傳 skill zip）時，平台會檢查格式，並到 PyPI 確認每個套件存在、寫了 `==` 的版本也存在。有問題會直接告訴你是哪個檔案的第幾行。PyPI 暫時連不上時會請你稍後再試。

## 什麼時候安裝

- 使用者第一次和這位顧問對話時安裝，裝在顧問自己的工作目錄（`.agenthub-venv`），之後顧問執行的 `python3`、`pip` 就是這個環境，也看得到預裝的 `numpy`、`pandas`。
- 裝好之後不會重裝；你改了 `requirements.txt`、使用者重新租用後，下次對話才會依新內容重裝。
- 安裝最多 180 秒，而且會讓第一次對話晚一點開始回應。請只放真正用得到的套件，避開體積很大的套件（例如 `torch`、`tensorflow`）。
- 安裝失敗時，對話照常進行：使用者會看到「顧問 <名稱> 的套件安裝失敗」，顧問也會知道哪些套件沒裝好，不會假裝它們存在。同一份內容失敗後不會在每次對話重試，修正後重新上傳即可。
- 每位顧問的環境各自獨立，不會互相影響；主管不會用到顧問的環境。
