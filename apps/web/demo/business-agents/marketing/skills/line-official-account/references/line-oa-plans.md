## 方案（2026-11-01 起，金額未稅）

| 方案 | 固定月費 | 每月免費訊息 | 加購訊息 | 其他 |
|---|---|---|---|---|
| 輕用量 | 0 元 | 200 則 | 不可加購 | 基礎功能 |
| 中用量 | 1,000 元（原 800 元） | 3,000 則 | 不可加購；要發更多須升級高用量 | 可免費啟用 OA PLUS 進階功能（自動貼標、開店幫手等） |
| 高用量 | 1,400 元（原 1,200 元） | 6,000 則 | 可加購，階梯式累進：第 1–50,000 則每則 0.2 元，第 50,001 則起每則 0.15 元 | 同上 |

- 加購只算超過免費則數的部分。例：高用量本月發 26,000 則 → 加購 20,000 則 × 0.2 元 ＝ 4,000 元，加月費 1,400 元，共 5,400 元（未稅）。
- 每月穩定 7 萬則以上：可了解 LINE 商家俱樂部會員計畫的訊息費折抵，或洽詢服務窗口。

## 訊息費怎麼算

- 每月訊息數 ＝ 目標好友數 × 每月群發次數。
- 群發、分眾、API 訊息都算；依發送的**目標好友數**計算。
- **不算**：一對一聊天訊息、自動回應訊息、加入好友的歡迎訊息、Messaging API 的 Reply API。
- 系統以日本時區（GMT+9）計算，台灣時間 23:00 起發送的訊息算到隔天。
- 月費只含帳號使用費，不含素材製作或 API 開發。

試算範例（示意）：好友 2,000 人，每月群發 4 次 → 8,000 則 → 超過中用量的 3,000 則，要用高用量：加購 2,000 則 × 0.2 元 ＝ 400 元＋月費 1,400 元 ＝ 1,800 元（未稅）。改成每次只分眾發給 700 位近期有互動的好友 → 2,800 則 → 中用量 1,000 元就夠。

## 帳號類型

| 類型 | 條件 | 可以多做的事 |
|---|---|---|
| 一般官方帳號 | 開設即有 | 基本功能。2026-04-01 起不再顯示過去俗稱的「灰盾」，改為不顯示盾牌 |
| 認證官方帳號（藍盾） | 需專屬 ID 並通過官方審核 | 可投放加好友廣告、申請企業贊助貼圖、LINE Beacon 等 |
| 企業官方帳號（綠盾） | 需專屬 ID 並通過官方審核 | 更進階的 API 功能 |

## 主要功能（官方頁面所列）

一對一聊天、群發訊息（可依性別、年齡、地區屬性篩選）、集點卡、圖文訊息、圖文選單、LINE Call、優惠券與抽獎、AI 聊天機器人與自動回應、分眾（曝光或點擊再行銷、聊天標籤、上傳顧客識別碼、依加入管道）、加好友廣告（認證帳號，可鎖定地區、半徑、興趣、年齡、性別）、OA PLUS（付費帳號可免費啟用）、開店幫手（中、高用量方案；官方頁面寫 0 元成交手續費、0 元上架費）、Messaging API 擴充（需技術人員或合作夥伴開發）。

聊天進階方案的 AI 聊天機器人（測試版）：官方說明醫療、金融、宗教、政治與行政機關、法律等可能觸及機敏資訊的業種，可能無法使用。
