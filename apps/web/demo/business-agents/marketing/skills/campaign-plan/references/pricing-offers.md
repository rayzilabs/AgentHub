# 定價與優惠設計

資料截至 2026-11-12（改寫自 marketingskills `offers`、`pricing`、`marketing-psychology`）。費率類數字（平台抽成、金流手續費）不寫在這裡，請老闆從自己的賣家後台或平台官方公告填入。

## 先算清楚：每份賣出去剩多少

```
實收金額（售價扣掉折扣、折價券之後，顧客實際付的錢）
－ 商品成本（原料、人工）
－ 包裝
－ 贈品成本（有送贈品時）
－ 商家負擔的運費（含免運時替顧客付的部分）
－ 平台抽成（蝦皮、momo、Pinkoi…依自己後台的費率與計算基礎）
－ 金流手續費（刷卡、行動支付）
＝ 每份剩下的錢
```
老闆還沒提供的費率（平台抽成、刷卡手續費）在試算裡寫成「〈請填：後台的費率〉」，**不要自己估一個區間**（例如「約 1.5%–2%」）。

每一項成本只扣一次：現金折扣已經反映在實收金額，贈品和免運則算在成本裡，不要再另外扣一次「優惠」。
這個數字小於 0 就是賠錢賣。要賠錢換新客時，老闆要明確知道並同意，並寫進企劃書的目標。

## 台灣常見的優惠形式

| 形式 | 適合 | 毛利陷阱 |
|---|---|---|
| 早鳥價、預購優惠 | 產能有限、想先確定量 | 早鳥比例太高，正價期沒人買 |
| 滿額免運 | 提高客單價 | 門檻設太低，免運吃掉毛利 |
| 滿額折、滿件折 | 提高客單價 | 搭配平台折價券時重複折扣 |
| 加價購 | 推第二件、清庫存 | 加價購商品成本要先算 |
| 第二件折扣 | 消耗品、送禮 | 只吸引原本就會買兩件的人 |
| 組合、禮盒 | 送禮檔期 | 包材成本與組裝人力 |
| 集點（LINE 集點卡） | 回購 | 兌換門檻太高沒人集、太低變成固定折扣 |
| 會員價、生日禮 | 會員經營 | 蒐集生日等個資要告知，請法務顧問確認 |
| 發票登錄抽獎、抽獎 | 拉好友、衝聲量 | 抽獎辦法、贈品規定、個資告知請法務顧問確認 |

## 選優惠的順序

1. 先問：顧客不買的原因真的是價格嗎？還是不知道、不相信、不方便？後三種改價值與流程（見 SKILL.md 的價值公式），不用打折。
2. 要給優惠時，優先選**不會讓顧客記住「這家要打折才買」**的形式：贈品、加價購、免運、組合，勝過直接打折。
3. 優惠一定要有期限與條件，寫清楚適用門市與通路。

## 定價

- **參考三個價格**：顧客的替代方案多少錢（對手、自己做）、你提供的價值、你的成本與目標毛利。價格落在前兩者之間，且高於成本。
- **好、更好、最好**：三個等級（例如單入、三入、禮盒），中間那個是你最想賣的；最高的那個讓中間看起來划算。
- **尾數**：台灣常見的 99、90、88 結尾，平價商品適合；強調品質與送禮的商品用整數看起來更體面。依品牌語氣決定，不必硬套。
- **錨點**：先看到高價選項，再看到主推選項，會覺得主推划算。「原價」必須是真的賣過的價格。

## 什麼時候該漲價

- 產能常常滿、預購常常秒殺
- 成本上漲，毛利掉到老闆設定的底線以下
- 顧客很少說貴，倒是常說「這個價格太佛心了」
- 對手陸續漲價

## 漲價怎麼做

1. 提前告知（LINE 群發、門市公告），說明原因（原料、人工），不必道歉。
2. 給老客一段緩衝：漲價前最後一次原價預購、或集點卡舊點數照舊。
3. 同時提高看得到的價值（包裝、份量說明、服務），但不要偷偷減量。
4. 漲價後一個月看來客數與客單價，結果寫進 `marketing-playbook`。
