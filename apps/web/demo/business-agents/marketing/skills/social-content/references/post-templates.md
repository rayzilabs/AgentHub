# 貼文與短影音範本（台灣在地商家）

資料截至 2026-11-12（結構改寫自 marketingskills `social/references/post-templates.md`、`short-form-video.md`）。範本裡的店名、數字都是示意，實際寫的時候換成老闆提供的真實資料。

## FB 粉專：幕後故事

```
凌晨 4 點，阿明已經在揉今天的第三批麵團。

很多人問為什麼我們的吐司隔天還是軟的。
答案很無聊：多花 6 個小時低溫發酵，不加改良劑。

今天的鮮奶吐司 12:00 出爐，一天只做 40 條。
想留一條的，LINE 私訊「留吐司」就好。
```
重點：第一句是畫面；中間一個具體做法；最後一個明確的下一步。

## IG 輪播：實用教學（5–7 張）

1. 封面：「隔夜麵包變好吃的 3 個方法」
2. 方法一：噴水＋烤箱 180 度 3 分鐘
3. 方法二：電鍋外鍋半杯水
4. 方法三：切片冷凍，要吃直接烤
5. 不要做的事：放冷藏（最容易變硬）
6. 結尾：「存起來下次用｜每週二、五有新口味」

說明文字第一行重複封面重點，最後提醒「存起來」「分享給常買麵包的朋友」。

## Threads：老闆觀察

```
開店第 8 年，最常被問的不是哪個最好吃，
而是「這個可以放幾天」。

所以我們把保存天數直接寫在標籤上了。
有時候顧客要的不是更多選擇，是少一點擔心。
```
短句、有觀點、像在聊天；不放連結也沒關係，重點是讓人回覆。

## 短影音腳本（30 秒）

```
[0–3 秒]  畫面：剛出爐的麵包被剝開。字幕：「這家店一天只做 40 條」
[3–10 秒] 為什麼：低溫發酵 18 小時的過程快剪
[10–25 秒] 怎麼吃：撕開、抹奶油、咬下去的聲音
[25–30 秒] 下一步：「12:00 出爐｜LINE 預留」＋店名與地址
```
提醒：直式 9:16、一定加字幕、前 3 秒不要放 Logo 或片頭。

## 限動

- 投票：「明天的限定口味：芋頭 or 紅豆？」
- 問答：「想問麵包怎麼保存的留在這裡」
- 倒數：檔期預購截止
- 精選限動分類：菜單、保存方式、交通、常見問題

## 檔期貼文

先用 tw-marketing MCP 的 `tw_calendar` 確認日期與連假。

```
今年母親節是 5 月 10 日（星期日）。

我們做了 3 種禮盒，4/20 開放預購，
5/5 前下單才來得及宅配到家。

LINE 輸入「母親節」，就能看到 3 種禮盒的內容和價格。
```
（示意為 2026 年；日期、天數依當年 `tw_calendar` 與實際出貨時間填寫。）
