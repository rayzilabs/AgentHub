# 台灣社群平台的使用狀況

資料截至 2026-11-12。

**出處**：財團法人台灣網路資訊中心（TWNIC）《2025 台灣網路報告》（`https://report.twnic.tw/`，2025 年 12 月發布）。TWNIC 是台灣的網域註冊管理機構（財團法人，不是政府機關）。調查方式：電話調查，市話 1,070 份＋手機 1,072 份有效樣本。

**更新方式**：TWNIC 每年 12 月發布新版報告；維護者下載新版 PDF，對照「最常使用的社群媒體」與「即時通訊軟體」的原表更新本檔數字與年份。引用時一律回原表核對，報告內文與表格偶有不一致（2025 年版內文寫 TikTok 2.25%，表格中 2.25% 其實是 PTT），以表格為準。

## 最常使用的社群媒體（表四-31）

問題：「請問您最常使用的社群媒體是哪個？」（單選，占全體民眾的比例）

| 平台 | 比例 |
|---|---|
| Facebook | 45.59% |
| Instagram | 18.70%（2024 年為 21.12%，下降） |
| Threads | 4.06%（首度排到第三） |
| TikTok | 3.72% |
| PTT | 2.25% |
| X | 1.06% |
| Dcard | 0.24% |

報告的解讀：Facebook 與 Instagram 近四年穩居前兩名，但作為主要平台的比例停滯或下降，民眾的平台選擇愈來愈分散。

## 其他

- 最常使用的即時通訊軟體：LINE 80.10%（以全體民眾計）。
- 過去三個月看過短影音的比例：78.46%（2025 年首次調查；短影音含 TikTok、IG Reels、Facebook 短片、YouTube Shorts）。
- TikTok 使用率：25.16%。

## 怎麼用這些數字

- 「最常使用」是單選，不代表其他平台沒人用；例如 Dcard 比例低，但年輕族群與特定話題（美妝、穿搭、感情、考試）討論集中，口碑影響大。
- 這是全體民眾的平均，**你的顧客不一定是平均值**。有自己的粉專洞察報告、LINE 官方帳號好友分析或顧客問卷時，以自己的資料為準。
- 不要把這些比例寫成「有多少人會看到你的貼文」。
