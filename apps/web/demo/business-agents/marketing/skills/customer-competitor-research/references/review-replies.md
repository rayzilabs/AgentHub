# Google 評論回覆範本

資料截至 2026-11-12。

**規範出處**：[Google 地圖使用者內容政策：禁止和受限內容](https://support.google.com/contributionpolicy/answer/7400114?hl=zh-Hant)（禁止用金錢、折扣、免費商品或服務換評論，或換顧客修改、刪除負評）。**更新方式**：每半年由維護者對照政策頁。

範本只是骨架，要改成老闆自己的語氣（看 `marketing-playbook` 的品牌語氣），而且**每一則都要提到評論裡的具體內容**，讓人看得出不是複製貼上。

## 好評

```
謝謝你特地寫下來！
芋頭吐司是我們每週二、五才做的，很高興你剛好買到。
下次來可以試試週末限定的桂圓核桃，我們店裡很多人的最愛。
```
要素：謝謝＋提到他說的具體內容＋一個自然的下一步（不要每則都推銷）。

## 有建議的普通評價

```
謝謝你的建議。
平日中午確實比較擠，我們從下週起加一位同事在櫃台，也可以先用 LINE 預留，到店直接取。
希望下次讓你有更好的經驗。
```
要素：承認＋具體改了什麼或會怎麼做＋方便的替代方案。

## 負評

**先私下處理**：建議老闆先用 LINE 或電話聯絡了解，處理完再公開回覆。

```
很抱歉這次讓你失望了。
我們已經私訊你了解當天的狀況，也確認了那批麵包的出爐時間。
之後會在裝袋前再檢查一次，謝謝你讓我們知道。
```
不要做的事：
- 爭辯、指責顧客、說「其他客人都覺得很好」
- 透露顧客的姓名、電話、訂單內容或消費細節
- 用折扣、贈品換對方刪除或修改評論
- 複製貼上同一段道歉

## 疑似假評論或惡意評論

不要在回覆裡指控。照實回覆一段簡短、有禮貌的說明（例如「我們查不到這天的消費紀錄，方便的話請私訊我們了解」），並請老闆依 Google 商家檔案說明中心的流程檢舉。
