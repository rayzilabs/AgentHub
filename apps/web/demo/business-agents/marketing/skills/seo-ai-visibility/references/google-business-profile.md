# Google 商家檔案檢查

資料截至 2026-11-12。

**出處**（Google 官方繁中說明）：
- [瞭解決定本地排名的因素](https://support.google.com/business/answer/7091?hl=zh-Hant)
- [在 Google 上呈現商家資訊的規範](https://support.google.com/business/answer/3038177?hl=zh-Hant)
- [Google 地圖使用者內容政策：禁止和受限內容](https://support.google.com/contributionpolicy/answer/7400114?hl=zh-Hant)

**更新方式**：每半年由維護者對照上面三頁，有變更就改本檔。

## 在地排名看什麼

Google 說明，本地搜尋結果主要取決於三件事；**商家不能用要求或付費的方式提升本地排名**。

| 因素 | 意思 | 商家能做的 |
|---|---|---|
| 關聯性 | 商家檔案和搜尋字詞吻合的程度 | 資訊填完整、類別精準、商品與服務項目寫清楚 |
| 距離 | 商家和搜尋者的距離 | 地址或服務範圍正確（這項改不了） |
| 顯著性 | 商家的知名度 | 連到你網站的其他網站、評論數量與評分；持續累積真實評論 |

## 檢查清單

| 項目 | 規範重點 |
|---|---|
| 認領與驗證 | 每個營業據點只能有一個商家檔案 |
| 名稱 | 必須和招牌、名片、網站上的實際名稱一致；**不能加地區、商品等關鍵字**（例如「阿明手作烘焙｜台中吐司推薦」不行） |
| 類別 | 寧少勿多、越精確越好 |
| 地址 | 有顯示地址就必須有標示商家名稱的固定招牌；地址欄不能放網址或關鍵字；沒有店面、到府服務的改設服務範圍 |
| 營業時間 | 國定假日、連假的特殊營業時間要另外設定（用 `tw_marketing__tw_calendar` 工具（tw-marketing MCP） 查連假） |
| 商家說明 | 介紹商家與特色；**不能寫特價促銷內容**（Google 舉的例子就是「超美味紅豆餅只要 20 元！」），也不能放連結 |
| 照片 | 門面、店內、商品、團隊；定期更新 |
| 商品／服務／菜單 | 填完整，用顧客會搜的說法 |
| 動態（貼文） | 檔期活動、新品放這裡 |
| 問與答、訊息 | 有人問就回 |

## 評論

**禁止**（Google 地圖使用者內容政策）：
- 用金錢、折扣、免費商品或服務等利益，換顧客發評論，或換顧客修改、刪除負評
- 要求顧客發布不是真實體驗的內容
- 到對手的頁面留評論毀損對方

**可以做**：
- 結帳、取貨、LINE 歡迎訊息時附上留評論的連結，請滿意的顧客留下真實心得（不附贈品）
- 每一則評論都回覆，回覆範本見 `customer-competitor-research` 的 `references/review-replies.md`
- 負評先私下了解並處理，再公開回覆處理結果；不要在回覆裡透露顧客的個資或消費細節
