# 頁面結構、標題公式與各段寫法

資料截至 2026-11-12（依 marketingskills `copywriting/references/copy-frameworks.md` 改寫為台灣中小商家常見頁面）。

## 標題公式（拿來發想，不要照抄）

| 類型 | 公式 | 例子 |
|---|---|---|
| 結果 | 得到〔結果〕，不用〔麻煩〕 | 「早餐不用排隊：前一晚 LINE 預訂，7 點到店直接取」 |
| 問題 | 點出讀者的困擾 | 「孩子挑食，連青菜都不碰？」 |
| 對象 | 給〔誰〕的〔東西〕 | 「給上班族的 15 分鐘午餐便當」 |
| 差異 | 只有我們〔做法〕 | 「每週一自己烘豆，咖啡豆不放超過 14 天」 |
| 證據 | 〔數字或第三方〕證明 | 「Google 評價 4.8 顆星、1,200 則評論的早午餐」（數字要老闆提供或查得到） |
| 在地 | 〔地區〕＋〔需求〕 | 「台中北屯，走路 5 分鐘的手作麵包」 |

標題寫完做「**現在你可以**」測試：在標題前面加「現在你可以……」讀起來通不通？不通代表標題沒講到讀者得到什麼。

## 首屏（打開頁面第一眼看到的）

1. **標題**：最重要的一句話，講讀者得到什麼。
2. **副標**：一兩句補具體內容（誰、在哪、怎麼做）。
3. **主要按鈕**：動詞＋得到什麼，例如「加 LINE 預訂明天的麵包」「預約週六試吃」。避免「送出」「了解更多」「點我」。
4. **一個證據**：評價分數、銷量、媒體報導、檢驗報告，擇一放在按鈕附近。

結構可以照「現在的困擾 → 更好的樣子 → 怎麼做到」排。

## 常用段落

| 段落 | 用途 | 寫法提醒 |
|---|---|---|
| 證據 | 讓人相信 | 真實評價截圖或原話、合作店家、媒體、檢驗報告；不能編 |
| 困擾 | 讓讀者覺得「你懂我」 | 用顧客原話描述，不要誇大成災難 |
| 好處 | 連到結果 | 3–5 個，各寫成「功能 → 對你代表什麼」 |
| 怎麼做 | 降低複雜感 | 3–4 步：「LINE 下單 → 選取貨時間 → 到店取」 |
| 疑慮 | 解決擔心 | 常見問答：運費、保存、退換貨、過敏原、發票 |
| 結尾按鈕 | 收尾 | 重述好處、再放一次按鈕、說明退換貨或保固 |

## 各種頁面

- **官網首頁**：講最大的價值，給不同來意的人各一條路（看菜單、找門市、線上訂）。
- **活動頁**：只講一件事、只有一個按鈕；標題要對得上帶人進來的廣告或貼文。
- **商品頁（官網、蝦皮、momo、Pinkoi）**：標題放顧客會搜的詞（品名、規格、用途、地區），不要堆砌；前三行講最重要的差異；規格、保存、出貨時間寫清楚；附常見問答。各平台的標題字數與規範以賣家中心公告為準。
- **關於我們**：為什麼開這家店、和顧客有什麼關係；最後也要放按鈕。
- **LINE 推播、簡訊**：第一行就講好處與期限，連結只放一個。（LINE 的細節交給 `line-official-account`）
- **廣告**：一則只用一個角度；圖上文字少；標題與到達頁的標題要一致。

## 證言挑選

挑**具體**的（講到結果或細節：「孩子連吃三天都說要」），不挑空泛的（「很好吃」）；附名字或縮寫與身分（老闆要先取得顧客同意）；不能改寫顧客原話的意思。
