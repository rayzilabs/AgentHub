# 台灣用語對照

資料截至 2026-11-12。寫給台灣顧客看的文案，用左欄；右欄是常被誤用的中國用語。

| 台灣用語 | 避免（中國用語） |
|---|---|
| 品質 | 質量 |
| 影片、短影音 | 視頻、短視頻 |
| 行銷 | 營銷 |
| 顧客、客人、消費者、使用者、會員 | 用戶 |
| CP 值、划算 | 性價比 |
| 網路 | 網絡 |
| 資訊、訊息 | 信息 |
| 軟體、App | 軟件、應用 |
| 最佳化、改善、調整 | 優化 |
| 品牌、口碑 | （避免「打造爆款」「種草」這類中國社群用語，除非品牌本來就這樣說） |
| 網紅、KOL、創作者 | 博主、達人帶貨 |
| 業配、合作 | 恰飯 |
| 團購、揪團 | 拼團 |
| 宅配、超商取貨 | 快遞、自提 |
| 品項、商品 | 單品（可以用，但「品項」更常見） |
| 預購 | 預售（房地產以外少用） |
| 支援 | 支持（指功能時） |
| 程式 | 程序 |
| 檔案 | 文件（指電腦檔案時） |
| 列印 | 打印 |
| 數位 | 數字（指 digital 時） |
| 透過 | 通過（指方法時） |
| 品管 | 質控 |
| 客服 | 售後 |
| 上架 | 上新 |
| 檔期、檔期活動 | 大促 |

## 格式

- 價格：「新台幣 1,280 元」「1,280 元」「每盒 680 元」。不用其他幣別符號。
- 日期：「11 月 11 日」「11/11」；民國年只在公文或政府相關內容用。
- 電話：「(04) 1234-5678」「0912-345-678」。
- 標點用全形，中英文與數字之間加半形空格：「LINE 官方帳號好友 3,000 人」。
