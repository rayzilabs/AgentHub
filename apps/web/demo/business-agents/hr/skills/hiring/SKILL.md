# 招募到錄取

目標使用者是第一次請人、或不常請人的老闆。產出要能直接貼到 104、1111、518、Yourator、CakeResume、LINE 群組或 FB 社團，也要能直接拿去面試。

## 開始前

1. `memory_read` `names: ["hr-playbook"]`，取得行業、人數、工時與薪資結構。沒有的話，至少問：這個職缺的工作地點、工時（全職、兼職、排班）、預計月薪或時薪範圍。
2. 問清楚這次要的是哪一段：職缺說明、面試、錄取通知，或從頭到尾。

## 一、職缺說明

### 要寫的內容

| 項目 | 寫法 |
|---|---|
| 職稱 | 用求職者會搜尋的名稱（「門市人員」比「零售夥伴」好找） |
| 工作內容 | 5–7 條具體工作，用動詞開頭；寫出每天實際在做什麼 |
| 必備條件 | 只寫做這份工作真的需要的技能、證照、經驗 |
| 加分條件 | 和必備分開寫，免得勸退合適的人 |
| 薪資 | **經常性薪資未達新臺幣 4 萬元，一定要寫薪資範圍**（就業服務法第 5 條第 2 項第 6 款，違反處 6 萬～30 萬元罰鍰，第 67 條）。4 萬元以上也建議寫，回應率較高。範圍的下限不能低於最低工資：115 年月薪 29,500 元、時薪 196 元；116/1/1 起月薪 30,900 元、時薪 205 元（勞動部 115/10/16 公告） |
| 工時與地點 | 上下班時間、休息、是否輪班、例假休息日怎麼排、工作地點 |
| 法定保障 | 勞保、健保、勞退 6% 提繳、特休，這些是法定義務，可以寫但不要包裝成「福利」 |
| 公司福利 | 法定以外的才是福利：年終保障月數、員工餐、補助、彈性上班 |
| 應徵方式 | 投遞管道、需要的資料、預計回覆時間 |

### 禁止的寫法（就業服務法第 5 條）

不得以種族、階級、語言、思想、宗教、黨派、籍貫、出生地、性別、性傾向、年齡、婚姻、容貌、五官、身心障礙、星座、血型或以往工會會員身分為由歧視；違反第 1 項處 30 萬～150 萬元罰鍰，並公布名稱（第 65 條）。性別、性傾向另有性別平等工作法第 7 條。

| 不要寫 | 改成 |
|---|---|
| 限男性、限女性 | 寫工作需求：「需搬運 20 公斤貨物」 |
| 限 35 歲以下、應屆畢業 | 「歡迎社會新鮮人」可以，但不能排除其他年齡；有年資需求就寫「2 年以上相關經驗」 |
| 外型佳、身高 160 以上 | 寫實際需求：「需穿著制服站立服務」；只有表演、模特兒等職務本質需要時才寫，並說明理由 |
| 未婚、無家累、可配合加班不請假 | 寫工時：「月平均加班約 10 小時，有加班費」 |
| 限本地人 | 寫通勤或駐點需求：「需能於 8:30 到台中市西屯區門市」 |
| 星座、血型、生肖 | 不寫 |
| 虛報薪資、把獎金上限寫成月薪 | 實際的保障底薪與獎金分開寫（不實廣告違反第 5 條第 2 項第 1 款，處 30 萬～150 萬元） |

## 二、面試

### 結構化面試

1. 從工作內容挑 4–6 項職能（例如顧客應對、數字正確、排班配合、學習速度）。
2. 每項配 1–2 題行為題（「請說一次……的經驗，你怎麼做？結果如何？」）和 1 題情境題（「如果……你會怎麼做？」）。
3. 評分表：每項 1–4 分，寫出 1 分與 4 分的具體樣子；每位應徵者用同一套題目和標準。
4. 面試後當天填寫，寫下具體事例，不寫「感覺不錯」。

範本與題庫見 `${CLAUDE_SKILL_DIR}/references/interview-kit.md`。

### 不能問、要小心問的問題

- 不能問：婚姻、懷孕或生育計畫、要不要生小孩、宗教、政治立場、星座血型、是否加入過工會、家庭背景、身心障礙或病史（與職務無關時）。
- 要小心：犯罪紀錄、信用紀錄、背景調查、藥物測試、心理測驗都屬於「隱私資料」（就業服務法施行細則第 1-1 條）。只有和職務有正當合理關聯時才能要求（例如保全、出納、需駕駛的職務），而且要事先說明目的。不能要求應徵者交身分證正本給公司保管，也不能收保證金（就業服務法第 5 條第 2 項第 2、3 款）。

### 求職者個資

- 收履歷時就是在蒐集個資，要告知：公司名稱、蒐集目的（招募）、資料類別、保存期間、當事人的權利（個人資料保護法第 8 條）。在徵才頁或面試通知加一段告知即可，範本見 `interview-kit.md`。
- 未錄取者的資料：在告知的期間後刪除，或經同意後留作人才庫。
- 聯絡前雇主做背景查核前，要取得應徵者同意，只問和職務有關的事。

## 三、錄取通知

錄取通知要寫清楚，因為它常被當成勞動條件的證據。內容：

1. 職稱、工作地點、到職日與報到時間、應攜帶文件。
2. 工資：底薪與每項固定津貼分開列（這些會影響加班費與勞健保勞退的計算基礎）；變動獎金另寫「依獎金辦法」。
3. 工時、休息、例假休息日與排班方式。
4. 試用期：期間與考核方式（試用期的規則見 `onboarding-contract`）。
5. 勞保、健保自到職日起加保，勞退依法提繳 6%。
6. 回覆期限，以及「正式勞動條件以勞動契約為準」。

範本見 `${CLAUDE_SKILL_DIR}/references/offer-letter.md`。

**撤回錄取的風險**：寄出錄取通知、對方也接受後，雙方對勞動條件已經有合意，公司片面撤回可能被認定為終止勞動契約，或要負締約上過失的損害賠償。發錄取通知前就要確定預算與職缺。

## 四、外籍人員

外國人（含港澳、陸籍）原則上要由雇主申請許可才能工作（就業服務法第 43 條）。白領、移工、外籍配偶與永久居留者規定各不同。遇到外籍應徵者，先問身分與居留證類別，再請使用者向勞動部勞動力發展署確認，這份 skill 不展開。

## 輸出格式

依使用者要的那一段給：
- 職缺說明：可直接貼上的全文，加一段「檢查結果」，列出已避開的歧視用語與薪資揭露狀況。
- 面試：題目、評分表、不能問的提醒。
- 錄取通知：全文，空白處用【　】標出要填的地方。
