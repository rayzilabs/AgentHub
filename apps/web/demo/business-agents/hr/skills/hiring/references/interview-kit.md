# 面試工具包

## 評分表範本

| 職能 | 題目 | 1 分（不符合） | 4 分（明顯超出） | 分數 | 具體事例 |
|---|---|---|---|---|---|
| 顧客應對 | 請說一次遇到不滿意的客人，你怎麼處理？ | 推給別人、和客人爭辯 | 先聽完、提出方案、事後回報主管 | | |
| 數字正確 | 你經手過哪些需要對帳或點貨的工作？怎麼避免出錯？ | 說不出方法 | 有固定的核對步驟，舉得出抓到錯誤的例子 | | |
| 時間與排班 | 遇過臨時要換班或支援的情況嗎？你怎麼安排？ | 沒有經驗也沒想過 | 主動協調、提前告知、說得出取捨 | | |
| 學習速度 | 最近學會的一個新工具或新流程是什麼？花多久？ | 想不出例子 | 講得出學習步驟與成果 | | |

用法：
- 每位應徵者問同一組主題題目，追問可以不同。
- 面試結束當天填完，「具體事例」寫對方說的事實，不寫印象。
- 決定錄取與否時對照分數與事例；未錄取的理由要和職能有關。

## 題庫（依職務挑選）

**行為題**（過去怎麼做）
- 請說一次你在期限很趕的情況下完成工作的經驗。你先做什麼？
- 請說一次你犯錯的經驗。你怎麼發現、怎麼處理？
- 請說一次你和同事意見不同的經驗。最後怎麼解決？
- 你在前一份工作最有成就感的一件事是什麼？你負責哪一部分？

**情境題**（遇到時會怎麼做）
- 下班前 10 分鐘，客人要求你處理一件要 30 分鐘的事，你會怎麼做？
- 你發現主管交代的報表數字和系統對不上，你會怎麼做？
- 你同時接到兩個主管交代的急件，你會怎麼排？

**動機與條件**
- 你為什麼想換工作、為什麼應徵這個職缺？
- 這份工作需要週末輪班（或需要搬運、需要出差），你可以配合的程度是？
- 你期待的薪資範圍？最快什麼時候可以到職？

## 不能問與可以改問的方式

| 不要問 | 為什麼 | 可以改問 |
|---|---|---|
| 結婚了嗎？有沒有打算生小孩？ | 婚姻、懷孕是就業服務法第 5 條、性別平等工作法第 7 條的歧視事由；懷孕計畫屬隱私資料 | 這份工作需要每月出差 3 天，你可以配合嗎？ |
| 你幾歲？什麼時候畢業的？ | 年齡歧視 | 你有幾年相關經驗？ |
| 你信什麼教？支持哪個政黨？ | 宗教、黨派、思想 | 不問 |
| 你是什麼星座、血型？ | 明文禁止 | 不問 |
| 你有沒有什麼病？有沒有吃藥？ | 生理資訊屬隱私資料 | 這份工作需要長時間站立（或搬運 20 公斤），你可以勝任嗎？ |
| 爸媽做什麼的？住哪裡、房子是租的嗎？ | 與職務無關的個人生活資訊 | 從住處到公司通勤大約多久？ |
| 請提供良民證、信用報告 | 犯罪與信用紀錄屬隱私資料（施行細則第 1-1 條），要和職務有正當合理關聯 | 只有出納、保全、駕駛等職務才要，並事先說明目的 |
| 你以前有參加工會嗎？ | 明文禁止 | 不問 |

## 求職者個資告知範本

> 【公司名稱】為辦理招募作業，蒐集您提供的姓名、聯絡方式、學經歷及履歷中的其他資料，僅用於本次及未來 【6 個月】 內的職缺評估與聯繫，不提供給第三人。您可以隨時請求查詢、閱覽、更正或刪除您的資料，請聯絡 【聯絡窗口與方式】。您可以選擇不提供部分資料，但可能影響我們評估您是否適合本職缺。期間屆滿後，未錄取者的資料將予刪除。

依據：個人資料保護法第 8 條。
