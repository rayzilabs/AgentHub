# 績效改善計畫（不能勝任之前要先做的事）

用「確不能勝任」（勞基法第 11 條第 5 款）資遣，法院會看雇主有沒有先給明確的標準、具體的回饋、改善的機會與協助。這份計畫就是在做這件事，也是在留下紀錄。不要把它當成資遣前的形式：員工真的改善了，計畫就成功了。

## 什麼時候用

- 員工的表現明顯低於職務要求，而且已經口頭提醒過。
- 不是用來處理單一違規（那是懲戒），也不是用來處理健康、家庭因素造成的狀況（先了解原因、考慮調整工作或請假）。

## 計畫內容

**員工**：＿＿＿＿　**職務**：＿＿＿＿　**主管**：＿＿＿＿　**期間**：＿＿＿＿ 至 ＿＿＿＿（常見 30–90 日）

| 項目 | 目前狀況（具體事例與數據） | 期待標準（可衡量） | 公司提供的協助 | 檢核日期 | 結果 |
|---|---|---|---|---|---|
| 例：出貨正確率 | 9 月 12 筆出錯，正確率 94% | 正確率 99% 以上 | 每週一次與資深同事對單；提供檢核表 | 每週五 | |
| | | | | | |

**檢核會議**：每 1–2 週一次，會後當天寫紀錄，請員工簽名（員工可寫意見）。

**期滿結果**：
□ 達成，結束計畫　□ 部分達成，延長＿＿日（說明）　□ 未達成，依公司規定處理

## 寫的時候注意

- 標準要和職務說明、同職務其他人的要求一致；不能為了讓人失敗而定得特別高。
- 協助要真的提供：訓練、工具、時間、帶領的人。
- 考慮過調到其他可以勝任的職務嗎？有沒有調職的可能，要寫下來（解僱最後手段性）。
- 不能因為員工懷孕、請育嬰假、職災、申訴或請病假（一年 10 日內）才啟動計畫（性別平等工作法第 21 條；勞基法第 74 條；勞工請假規則第 9-1 條）。
- 期滿未達成要資遣時，回到 SKILL.md 走完高風險旗標、計算與程序。
