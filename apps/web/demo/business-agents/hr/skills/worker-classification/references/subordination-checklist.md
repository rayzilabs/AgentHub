# 從屬性對照表

依勞動部〈勞動契約認定指導原則〉（108/11/19 訂定）的判斷要素整理。勞動部另有〈勞動契約從屬性判斷檢核表〉共 25 項，是這些要素的細項，正式判斷請以勞動部網站公告的檢核表為準：https://www.mol.gov.tw/1607/1632/1640/12431/

標記：✔ 符合（有從屬性特徵）　✘ 不符合　？ 不清楚

## 一、人格從屬性（8 項要素）

| 要素 | 判斷 | 標記 |
|---|---|---|
| 1. 工作時間受公司指揮或管制約束 | 要打卡、排班、固定上下班、請假要核准 | |
| 2. 給付勞務的方法受公司指揮或管制約束 | 公司規定作業流程、話術、順序、標準作業程序 | |
| 3. 勞務地點受公司指揮或管制約束 | 要在公司指定的地點工作 | |
| 4. 不能拒絕公司指派的工作 | 拒絕會被處罰或影響報酬 | |
| 5. 必須接受公司的考核 | 有績效考核、評比、升降 | |
| 6. 必須遵守服務紀律並接受懲處 | 適用工作規則、服裝儀容、記過扣款 | |
| 7. 必須親自提供勞務 | 不能找人代做或轉包 | |
| 8. 不能以自己的名義提供勞務 | 對外以公司名義、用公司職稱與信箱 | |

## 二、經濟從屬性（5 項要素）

| 要素 | 判斷 | 標記 |
|---|---|---|
| 1. 不論有無工作成果，公司都會計給報酬 | 按月、日、時計酬，沒有成果也有錢 | |
| 2. 不須負擔營業風險 | 損失、材料、瑕疵修補都由公司負擔 | |
| 3. 不須自行備置勞務設備 | 工具、設備、軟體、車輛由公司提供 | |
| 4. 只能依公司訂立或片面變更的標準取得報酬 | 費率由公司公告、可以單方調整 | |
| 5. 只能透過公司提供勞務，不得與第三人私下交易 | 不能自己接客戶或同時為競爭對手工作 | |

## 三、組織從屬性

| 要素 | 判斷 | 標記 |
|---|---|---|
| 要和公司其他人分工合作才能完成工作 | 被編進部門、班表、組織圖，參加內部會議 | |

## 四、參考事項

| 事項 | 說明 |
|---|---|
| 勞工保險 | 由公司以勞工身分投保，是勞動契約的參考；沒投保不代表不是勞工 |
| 薪資扣繳 | 以薪資所得扣繳是參考；以執行業務所得扣繳不代表不是勞工 |
| 相同勞務的契約性質 | 公司裡做同樣工作的人簽的是什麼契約 |

## 怎麼讀結果

- 符合的項目越多，越可以合理推論是勞動契約，但仍要看整體契約內容與實際受拘束的程度綜合判斷。
- 時間、地點、方法都受指揮，加上按時間計酬、不負營業風險，幾乎一定是勞動契約。
- 實際做法和契約文字不一樣時，以實際做法為準。
