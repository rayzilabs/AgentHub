# 薪資與勞健保勞退

**所有金額一律用 taiwan_payroll 工具計算，不要心算。** 這個工具依勞保局、健保署公告的級距與費率計算，已用官方範例驗證過。

## 開始前

1. `memory_read` `names: ["hr-playbook"]`：薪資結構（哪些項目每月固定）、發薪日、有沒有自提勞退。
2. 確認計算的年度。先呼叫 `taiwan_payroll__list_years` 看工具有哪些年度：
   - 有該年度：照常計算，回答寫「依 ○○ 年度級距與費率」。
   - **沒有該年度**（例如 116 年的分級表還沒公告、工具還沒更新）：說明「116 年度分級表尚未公告或尚未更新，以下用 115 年度資料估算」。並提醒 116/1/1 起最低工資為月薪 30,900 元、時薪 205 元（勞動部 115/10/16 公告），勞保第一級投保薪資通常會配合調整，正式數字以勞保局公告為準。
   - 工具回傳錯誤或連不上：不要自己算，請使用者用勞保局、健保署的官方試算，並附上網址（見 `${CLAUDE_SKILL_DIR}/references/annual-figures.md`）。

## 一、每月勞健保勞退

工具：`taiwan_payroll__calculate_payroll`

需要的資料：
- `monthlySalary`：**月薪資總額**，也就是底薪加每月固定發的津貼、獎金，不是只看底薪（勞工保險條例第 14 條；勞工退休金條例第 14 條）。
- `dependents`：健保眷屬人數，計費最多 3 口。
- `pensionSelfContribution`：員工自願提繳率（0～6%）。
- `identity`：本國勞工或外籍配偶用預設值；一般移工、家事移工另選。
- 部分工時員工：提供實際月薪，工具會處理部分工時的較低級距。

回答時列出：
| 項目 | 投保級距 | 員工自付 | 公司負擔 | 政府負擔 |
|---|---|---|---|---|
| 勞保（含就保） | | | | |
| 健保 | | | | |
| 勞退 | | 自提 | 6% | — |
| 職災保險 | | — | | — |
| 合計 | | | | |

再加一行「**公司每月總人事成本 = 工資總額 + 公司負擔合計**」，老闆最常要的是這個數字。

職災保險費率依行業別而定，工具預設用各業平均費率；行業別費率請使用者在勞保局的通知裡確認，或傳 `occupationalRate`。

## 二、到職或離職當月（破月）

工具：`taiwan_payroll__calculate_prorated`，給 `startDate`（到職日）或 `endDate`（離職日）。

- 勞保、職災、勞退按實際在職天數計算。
- 健保看月底：月底在職就收整個月，月中離職的當月不收（由下一個投保單位或地區人口投保）。

## 三、投保薪資怎麼報、何時調整

- 依月薪資總額對照分級表申報，**不能以多報少**：短報的保險費差額處 4 倍罰鍰，勞工因此受的損失（例如給付變少）由公司賠償（勞工保險條例第 72 條第 3 項）。勞退申報不實，勞保局可以逕行更正並追溯（勞工退休金條例第 15 條第 3 項）。
- 調薪時：2～7 月調整的，8 月底前申報；8 月～次年 1 月調整的，次年 2 月底前申報，都從申報的次月 1 日起生效（勞工保險條例第 14 條第 2 項；勞工退休金條例第 15 條第 2 項）。健保也要配合調整。
- 未滿 5 人的公司行號，勞保（普通事故）可以自願加保；**就業保險、職災保險、健保不論人數都要保**（見 `onboarding-contract`）。只保就保與職災時，計算結果的勞保欄位要扣掉普通事故的部分，請使用者以勞保局繳款單為準。

## 四、薪資所得扣繳

工具：`taiwan_payroll__calculate_income_tax_withholding`

| 情況 | `type` | 說明 |
|---|---|---|
| 本國人或居住者每月固定薪資 | `resident` | 依薪資所得扣繳稅額表；`dependents` 填申報的受扶養人數 |
| 年終、三節獎金等非每月給付 | `residentBonus` | 5%，未達起扣標準免扣 |
| 非居住者（一年在台未滿 183 天的外籍人士） | `nonResident` | 18%；月薪在最低工資 1.5 倍以下為 6% |

期限：每月 10 日前把上個月扣的稅款繳庫；每年 1 月底前申報上一年度的扣繳憑單，2 月 10 日前發給員工（1 月有連續 3 天以上國定假日時，分別延到 2 月 5 日、2 月 15 日）（所得稅法第 92 條）。

## 五、二代健保補充保費

| 對象 | 工具 | 規則 |
|---|---|---|
| 員工的獎金 | `taiwan_payroll__calculate_supplementary_premium`，`type: "bonus"` | 全年累計獎金超過當月投保金額 4 倍的部分，乘以補充保費率；要給 `monthlyInsuredSalary`（當月健保投保金額）與 `ytdBonus`（今年已發的獎金累計） |
| 非本公司投保的兼職薪資 | 同上，`type: "parttime"` | 單次給付達門檻就全額計收 |
| 付給外部講師、設計師等的執行業務報酬 | 同上，`type: "professional"` | 單次給付達門檻就全額計收 |
| 公司負擔 | `taiwan_payroll__calculate_employer_supplementary_premium` | （每月薪資總額 − 受僱者投保金額總額）× 補充保費率（全民健康保險法第 34 條） |

補充保費由公司在給付時扣取，給付日的次月底前繳納（全民健康保險法第 31 條）。

## 六、薪資單與工資清冊

- 每次發薪要給工資各項目的計算明細：議定的工資總額、各項目金額、依法或約定扣除的項目、實發金額（勞基法第 23 條；施行細則第 14-1 條）。紙本或電子都可以。
- 工資清冊記載發放工資、各項目計算明細與工資總額，**保存 5 年**（勞基法第 23 條第 2 項）。特休未休折發的金額也要記在工資清冊（第 38 條第 5 項）。
- 扣款：法定扣款（勞健保自付額、勞退自提、所得稅、法院扣押）以外，其他扣款要有勞工同意（第 22 條第 2 項），而且不能預扣工資當違約金或賠償（第 26 條）。
- 工資不能低於最低工資（最低工資法第 5 條；違反處 2 萬～100 萬元罰鍰，第 17 條）。比較時用正常工時的工資，不含加班費與假日加給（施行細則第 11 條）。

## 輸出格式

1. 一句話結論（例如「月薪 36,000 元，公司每月總成本約 43,187 元」）。
2. 上面的計算表，註明「依 ○○ 年度級距與費率，taiwan_payroll 試算」。
3. 需要注意的事（投保薪資是否少報、年度是否跨年、職災費率是否為行業別）。
4. 「以上為試算，實際以勞保局、健保署寄發的繳款單為準。」
