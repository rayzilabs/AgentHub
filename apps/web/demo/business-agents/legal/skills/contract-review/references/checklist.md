# 合約八大類檢查清單（台灣中小企業版）

資料截至 2026-11-12。條文以全國法規資料庫為準，引用前用 taiwan-law 查證。

## 1. 付款與金流

| 看什麼 | 一般市場標準 | 要標出來的情況 |
|---|---|---|
| 付款期限 | B2B 月結 30 天常見；60 天可談；90 天以上要爭取 | 月結 90 天以上、「客戶收到其客戶款項後才付款」（背對背付款） |
| 付款條件 | 交貨或驗收後開發票、依約付款 | 驗收沒有期限、或「驗收合格」由對方主觀認定 |
| 票據 | 現金、匯款；收票要注意票期 | 收遠期支票且票期很長 |
| 遲延利息 | 沒約定時依民法第 233 條、第 203 條，週年利率 5%；約定利率超過**週年 16%** 的部分無效（第 205 條） | 我方是付款方卻約定很高的遲延利息。建議改法不要超過週年 16%（例如「每日萬分之五」換算約 18.25%，已超過） |
| 調價 | 長約有調價機制（物價指數、原料） | 價格固定多年、或只有對方能調價 |
| 發票與稅 | 寫清楚含稅或未稅（營業稅 5%） | 只寫「價格」沒寫含不含稅 |
| 定金或訂金 | 寫「定金」適用民法第 248、249 條（因付定金方可歸責而不能履行，定金不得請求返還；因收定金方可歸責，要加倍返還）；寫「訂金」常被當成預付價金，效果有爭議，用語要寫清楚 | 我方付了大筆款項，合約卻沒寫不能履行時怎麼退 |

## 2. 責任與賠償

| 看什麼 | 建議 |
|---|---|
| 賠償範圍 | 民法第 216 條預設是所受損害＋所失利益。賣方或服務提供方應爭取「以直接損害為限，不含所失利益」 |
| 賠償上限 | 常見寫法：以該合約已付（或最近 12 個月）總額為限。注意：**故意或重大過失的責任不能事先免除**（民法第 222 條），上限條款要寫「故意或重大過失除外」才不會整條被挑戰 |
| 單方賠償 | 只有我方要賠、對方不用賠 → 改成雙方對等 |
| 第三人求償（美式 indemnification） | 見 `us-vs-tw-clauses.md` |
| 保險 | 要求我方投保的金額是否合理、保得到 |
| 瑕疵擔保 | 買賣依民法第 354 條起、承攬依第 492 條起；縮短或排除擔保要看我方是哪一方 |

## 3. 違約金

- 民法第 250 條：違約金沒特別約定時「視為損害賠償總額」；約定為「懲罰性違約金」時，可以另外請求損害賠償。看清楚是哪一種。
- 民法第 252 條：違約金過高，法院可以酌減。所以**對方開很高的違約金不代表一定要付那麼多**，但要打官司才能減，所以談判時就要先壓下來。
- 民法第 251 條：已經部分履行，法院可以比例減少。
- 定型化條款（一方預先擬定、用於同類契約）加重他方責任且顯失公平，依民法第 247-1 條該部分無效。
- 實務參考：違約金超過合約總價三成要特別爭取；「每遲延一日按總價千分之一」這類算法要設上限（例如以總價 10% 為上限）。

## 4. 解約與退場

| 看什麼 | 建議 |
|---|---|
| 任意終止 | 雙方都能提前終止，預告 30 天常見；只有對方能終止要改 |
| 違約解除 | 要有「通知後 N 日內改善」的寬限期；民法第 254 條本來就要求定相當期限催告 |
| 自動續約 | 期滿自動續約可以，但要有不續約的通知期限，並把期限記進行事曆 |
| 終止後 | 已完成部分如何付款、資料與物品返還、過渡協助是否另計費 |
| 委任契約 | 民法第 549 條：雙方可以隨時終止，但在不利於他方的時期終止要賠償 |
| 承攬契約 | 民法第 511 條：定作人在工作完成前可以隨時終止，但要賠償承攬人損害 |

## 5. 智慧財產

- 委外完成的設計、程式、文案、照片：著作權法第 12 條，**沒約定就歸受聘人**，出資人只能利用。要成果歸公司，合約要寫「著作財產權歸甲方，乙方不行使著作人格權」。
- 員工職務上完成的著作：著作權法第 11 條，著作財產權預設歸雇用人（員工合約問人資顧問）。
- 我方原有的工具、程式庫、範本：要寫「乙方既有智慧財產仍屬乙方，僅授權甲方於本案使用」，否則可能被一起移轉。
- 授權使用對方的軟體或素材：看授權範圍（期間、地區、用途、可否轉授權）。
- 使用到第三方素材（字型、圖庫、開源軟體）：誰負責取得授權。

## 6. 範圍與驗收

- 工作內容具體嗎（規格、數量、交期、交付物）？「依甲方需求」這種寫法會無限擴張。
- 變更流程：追加工作要書面確認並另行報價。
- 驗收：有沒有期限、標準是否客觀、逾期未表示是否視為驗收合格。
- 時程：我方遲延要罰，對方遲延（不提供資料、不回覆）有沒有對應的展延。

## 7. 保密與個資

- 保密範圍是否過廣（「一切資訊」且無除外）、期間是否合理（終止後 2–3 年常見，營業秘密另計）。
- 合約涉及把客戶個資交給對方處理（物流、客服、行銷代理、雲端）：我方是委託人，依個資法施行細則第 8 條要能監督受託者，合約要有對應條款 → 改用 `privacy-check` 的委外檢查表。

## 8. 管轄與其他

- 管轄法院：民事訴訟法第 24 條允許合意定第一審管轄法院，要以文書證之。爭取公司所在地的地方法院。
- 仲裁：仲裁法第 1 條，仲裁協議要書面。仲裁比較快但費用不低、原則上一審終局；小金額爭議不一定划算。
- 準據法：與外國公司簽約要寫「中華民國法律」。
- 讓與：對方被併購或把合約轉給別人時，我方能不能同意或解約。
- 通知：寫明通知的地址與方式（Email 是否有效）。
- 合約生效：大小章、簽名、日期；騎縫章；修改要雙方書面同意。
- 印花稅：依印花稅法，承攬契約等憑證可能要貼印花，請會計確認（不在本清單範圍）。
