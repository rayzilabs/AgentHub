# 美式（英文）合約條款在台灣怎麼理解

外國公司或用英文範本的合約常有下列條款。台灣法下概念不同，審閱時要說明差異並給台灣化的改法。準據法若約定外國法，實際適用以該國法為準，金額大時建議找律師。資料截至 2026-11-12。

| 英文條款 | 台灣法下怎麼看 | 建議 |
|---|---|---|
| **Indemnification / hold harmless**（補償並使對方免責） | 台灣沒有獨立制度，是一種契約上的損害賠償與第三人求償約定。範圍常寫成「任何第三人主張」「包含律師費」，比民法第 216 條的損害賠償更廣 | 限縮為「因可歸責於乙方之事由，致甲方遭第三人請求而受有損害者」；律師費以合理且經法院認定者為限；設上限；改成雙方對等 |
| **Consequential / indirect damages**（間接、衍生損害） | 民法沒有這個分類，第 216 條是「所受損害」與「所失利益」。英文合約排除 consequential damages，在台灣大致對應排除「所失利益」與間接損害，但界線不清楚 | 直接寫「不負所失利益及間接損害之賠償責任」，並列舉（營業損失、商譽、資料遺失） |
| **Limitation of liability** | 可以約定，但故意或重大過失的責任不能預先免除（民法第 222 條）；定型化條款顯失公平者無效（第 247-1 條） | 上限寫成「以本合約已付總額為限，但故意或重大過失不在此限」 |
| **Liquidated damages** | 對應「違約金」。民法第 250 條預設是損害賠償總額預定；第 252 條過高可酌減 | 寫清楚是「損害賠償總額預定性違約金」還是「懲罰性違約金」 |
| **Warranty / disclaimer（AS IS）** | 對應瑕疵擔保（買賣第 354 條起、承攬第 492 條起）。出賣人故意不告知瑕疵時，免除擔保的特約無效（第 366 條） | 我方是買方：至少保留重要瑕疵的修補或退款；我方是賣方：明確寫保固範圍與期間 |
| **Governing law: State of Delaware / New York** | 準據法依涉外民事法律適用法；在台灣法院打官司要證明外國法，成本高 | 爭取「中華民國法律」與「臺灣 OO 地方法院為第一審管轄法院」（民事訴訟法第 24 條） |
| **Arbitration (AAA / ICC / JAMS)** | 台灣可以約定仲裁（仲裁法第 1 條），國內有中華民國仲裁協會。國外仲裁費用與時間成本很高 | 小金額合約改成台灣法院；要仲裁就寫中華民國仲裁協會、在台北仲裁、中文進行 |
| **Injunctive relief** | 對應假處分、定暫時狀態處分（民事訴訟法保全程序），要向法院聲請，合約不能代替法院決定 | 可以保留，但不要同意「不需提供擔保」這種放棄權利的寫法 |
| **Non-compete / non-solicit（商業合作方）** | 商業合作的競業約定原則上依契約自由，但範圍過廣可能違反公平交易法或被認定顯失公平 | 限定期間、地區、業務範圍；**員工競業**不在本 skill，請問人資顧問 |
| **Assignment / change of control** | 民法債權讓與原則上可以（第 294 條），債務承擔要債權人同意（第 301 條） | 約定對方轉讓或被併購時我方可以解約 |
| **Entire agreement** | 可以約定，但會排除先前的 Email、報價單承諾 | 重要承諾（價格、交期、保固）要寫進合約本文或附件 |
| **Notices by email** | 可以約定 | 寫明指定的 Email 與「寄出後 N 日視為送達」 |
| **Force majeure** | 民法有不可歸責的給付不能規定（第 225 條），合約可以更具體 | 列舉事由（天災、疫情、政府命令、網路中斷），並約定持續多久可以解約 |
| **Most favored nation（最惠待遇）** | 可約定 | 我方是賣方時盡量不要接受，會限制對其他客戶的定價 |
