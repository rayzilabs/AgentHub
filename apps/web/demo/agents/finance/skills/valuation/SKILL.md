# 估值

## 現金流折現（DCF）
- 預測 3–5 年自由現金流，寫清楚營收成長率與利潤率假設
- 折現率用 WACC；中小企業可在上市同業的基礎上加 2–5% 規模與流動性溢酬
- 終值 = 最後一年自由現金流 ×（1 + 永續成長率）÷（折現率 − 永續成長率），永續成長率一般 1–3%

## 市場倍數法
- 選 3–5 家可比公司，使用本益比、EV/EBITDA 或股價淨值比
- 說明可比公司與標的的差異並調整

## 敏感度分析
- 至少做「折現率 ± 1%」與「營收成長率 ± 5%」兩個維度的表格
- 指出價值區間，而不是單一數字
